# NativeBridgeGuard v0.1 Acceptance Gate

This is the acceptance gate for v0.1. It is deliberately split into two layers
that must **not** be conflated:

- **AUTOMATED** — reproducible unit tests that run anywhere.
- **REAL WINDOWS** — checks that only mean anything when executed on a real
  Windows machine with real Chrome/Edge installed.

Green unit tests alone do not satisfy this gate. Two defects in this release
passed unit tests and still failed on a real machine (see
[evidence/debugging_cases.md](evidence/debugging_cases.md)).

No raw machine logs are embedded here. Sanitized records live in
[`docs/evidence/`](evidence/acceptance_summary.md); machine-specific raw output
(username, host name, absolute profile paths, unrelated installed software)
is intentionally excluded from the repository.

## Defects found by real-machine validation

| # | Defect | Fix |
|---|---|---|
| 1 | Writable detection used `os.access`, which is not a Windows ACL judgement → false positives on protected OS locations | DACL-parsing heuristic with `Deny` precedence and parent-directory consideration |
| 2 | Unpacked-extension collector read only `Preferences`; current browsers store those settings in `Secure Preferences` → collector silently returned nothing, with green unit tests | Read both sources, Secure Preferences wins, sources isolated; 6 regression tests added |
| 3 | Task Scheduler installer produced an out-of-range repetition duration → registration failed silently | Bounded duration; registration errors surfaced; success verified by re-query |

Details and boundaries: [evidence/debugging_cases.md](evidence/debugging_cases.md).

---

## Known boundaries carried into v0.1

These are accepted limits of the current version, not open defects:

- The ACL writable hint is a **heuristic**, not Windows Effective Access / AuthZ.
- The monitor is **schedule-driven**, not a real-time watcher.
- Live collection is **Windows + Chrome/Edge only**.
- Extension discovery focuses on `Default` and `Profile *` profiles.
- Browser on-disk preference layout is an undocumented internal and may change.
